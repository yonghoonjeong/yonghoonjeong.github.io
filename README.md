# Yonghoon Jeong

Source for [yonghoonjeong.github.io](https://yonghoonjeong.github.io/), built with Jekyll on GitHub Pages.

## Content

- `_data/data.yml`: profile, research, publications, experience, and contact information.
- `index.html`, `_includes/`, and `_layouts/default.html`: homepage structure.
- `activities/` and `assets/images/`: activity galleries, current portrait, and thumbnails.
- `assets/css/`, `_sass/`, and `assets/js/homepage.js`: presentation and interactions.
- `Yonghoon_Jeong_CV.pdf`: current downloadable CV.
- Root favicon assets: approved blue wave and foreground anchor.

## Local preview

Run `bundle install`, then `bundle exec jekyll serve`.
Keep gallery image paths and the CV link in sync when replacing files. Older versions remain available in Git history.
